# ❀抖音短视频采集工具

Windows 10/11 64 位本地工具。无需安装 Codex 或 Python，视频转文字在自己的电脑完成。

## 下载

[打开最新版下载页](https://github.com/huacreate/douyin-short-video-tool-releases/releases/latest)

- 第一次用：在发布页 Assets 中下载 `DouyinTool-Windows-x64.zip`，右键“全部解压”，双击里面的启动文件。按包内《新手图解》准备 Chrome 并登录自己的抖音账号。
- 已有工具：下载 `DouyinTool-Update.zip`，全部解压，运行“更新工具.exe”。V1.3/V1.4 首次升级前，请在旧工具中点“退出工具”。更新保留任务、文案和视频。
- 不要下载 GitHub 自动生成的 `Source code`：它只是本仓库的公开说明，不是安装包，也不包含核心程序源码。

## 使用与资料

输入或搜索主播，确认账号后采集公开可访问作品，验片、本地转写并导出 Word；飞书交付由使用者独立授权。遇验证码需本人完成，不能保证任意账号、任意网络下均能完整采集。自动转写需人工核对。

每位使用者的登录、任务、视频和文案保存在自己的电脑。此仓库只提供公开说明、版本记录和校验信息；发行附件为干净编译包，不含制作者的个人使用资料。

“主播资料”中的“删除本地视频”由你自行确认，文案、Word 和任务记录保留。默认移入回收站，回收站仍占磁盘空间，可自行核对后清空。

## 问题反馈

点击工具右上角“问题反馈”，查看脱敏排查信息后交给维护者。不要公开上传账号凭据、Cookie、浏览器资料或私人视频。

本工具无必需 AI 接口或服务器订阅费用，仍使用自己的电脑、网络、硬盘和电力。第三方组件许可证随程序保留。
